# NAXA — Site officiel

Agence digitale spécialisée en **IA locale**, **automatisation métier** et **chatbots intelligents**.

## Structure

```
site web/
├── index.html          Accueil
├── services.html       4 offres + tarifs
├── solutions.html      8 cas d'usage IA
├── a-propos.html       Mission, valeurs, équipe
├── contact.html        Formulaire → WhatsApp
├── css/style.css
├── js/main.js
└── assets/
    ├── logo.svg
    └── favicon.svg
```

## Lancer en local
Double-clique sur `index.html` — c'est un site 100% statique.

## Remplacer le logo par ton fichier officiel
Remplace `assets/logo.svg` par ton fichier (SVG, PNG ou JPG).
Si extension différente, mets à jour la balise dans les 5 pages :
```html
<img src="assets/logo.png" alt="" class="logo-mark" />
```
